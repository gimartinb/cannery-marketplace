# Vendor directory guide

## How this will work

The vendor directory will use **Airtable** as its simple editing screen. You will not need to edit the website code. You will open one table, add or update a vendor record, and the website will use those records to build the directory cards and profile pages.

For the first preview, the site uses four temporary profiles so you can see the layout. Those examples are not real vendors and should be replaced before launch.

## The vendor fields

Each vendor will have one row in the Airtable table.

| Field | What to enter |
|---|---|
| Vendor name | The public name customers should see |
| Category | One short category, such as Ceramics or Paper & Art |
| Bio | Two or three friendly sentences about the maker and their work |
| Photo | One square or portrait photo that shows the work clearly |
| Social link | The vendor’s Instagram, Facebook, or website URL |
| Active | Turn this on when the profile should be visible |
| Featured | Turn this on only for makers you want to highlight |
| Display order | A number such as 1, 2, or 3 to control the grid order |

## Adding a new vendor

1. Open the Cannery Marketplace vendor table.
2. Click the first empty row or choose **Add record**.
3. Enter the vendor name and category.
4. Paste the short bio into the Bio field.
5. Add the photo in the Photo field. A clear image with the product filling most of the frame works best.
6. Paste the vendor’s social link.
7. Turn **Active** on.
8. Leave **Featured** off unless the maker should be highlighted.
9. Add a display-order number if you want to control where the profile appears.
10. Save the record. The website will show the vendor after the next content refresh.

## Editing or hiding a vendor

To change a profile, open its row, update the field, and save. To hide a profile without deleting it, turn **Active** off. This is safer than deleting the record because the profile can be restored later.

## Photo tips

Use a well-lit photo that is at least 800 pixels wide. Avoid adding text or a collage to the image. A photo of the vendor’s work is usually more helpful than a logo. If a vendor does not have a suitable photo yet, leave the record inactive until one is available.

## Important safety rule

Only people who have been approved by the marketplace owner should receive access to the Airtable base. The public website will show approved vendor information, but visitors will not be able to edit it.

## Stage 2 setup still needed

The live connection requires an Airtable workspace and a base owned or approved by the marketplace owner. No Airtable account, billing plan, or API token has been created by this project. Once the account is ready, the site connection can be completed without changing the directory design.
